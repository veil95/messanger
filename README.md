# Микросервис аутентификации (FastAPI)

## Описание

Данный проект представляет собой backend-микросервис аутентификации и авторизации, разработанный с использованием FastAPI. Сервис обеспечивает безопасную работу с пользователями за счёт применения современных подходов к защите данных и управлению доступом.

Проект реализован в рамках командной разработки с использованием практик code review и Git workflow.


## Функциональность

* Регистрация и аутентификация пользователей
* Безопасное хэширование паролей
* JWT-аутентификация (access и refresh токены)
* Валидация и обновление токенов
* Ограничение количества попыток входа (rate limiting)
* Валидация входных данных (Pydantic)
* Модульная архитектура (MVC-подход)


## Архитектура

Проект построен с использованием модульной архитектуры, близкой к паттерну MVC (Model-View-Controller):

* Models — схемы данных и валидация (Pydantic)
* Controllers — бизнес-логика (аутентификация, работа с JWT, хэширование)
* Routes (Views) — HTTP-эндпоинты (FastAPI роутеры)

Такое разделение упрощает поддержку, тестирование и масштабирование сервиса.


## Технологический стек

* Python 3
* FastAPI
* Pydantic
* python-jose (JWT)
* python-dotenv


## Безопасность

В проекте реализованы следующие механизмы безопасности:

* Хэширование паролей (без хранения в открытом виде)
* JWT-аутентификация (access и refresh токены)
* Ограничение времени жизни токенов
* Проверка валидности токенов
* Ограничение количества попыток входа (rate limiting)
* Использование HTTP-only cookie для refresh токена

## Переменные окружения

Создайте файл .env со следующими параметрами:

```
SECRET_KEY=your_secret_key
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=15
REFRESH_TOKEN_EXPIRE_DAYS=7
```


## Запуск проекта

Установка зависимостей:

```
pip install -r requirements.txt
```

Запуск сервера:

```
uvicorn main:app --reload
```


## API эндпоинты

Аутентификация:

* POST /auth/register — регистрация пользователя
* POST /auth/login — вход пользователя
* GET /auth/me — получение информации о текущем пользователе (требуется access token)

Токены:

* POST /auth/refresh — обновление access token по refresh token
